### 第 1 项根因

`TaskRepository.isSessionEligible()` 在没有当前任务时直接返回 false，首次提醒、稍后提醒、提醒 Activity 与按钮操作共享此检查；`AppSessionCoordinator.refreshTaskContext()` 又只在新任务 ID 非空时重启提醒。因此守护被错误地绑定到了进行中任务。

### 第 1 项实施记录

- 已修改 `TaskRepository.isSessionEligible()`：没有当前任务且会话没有任务 ID 时允许通用提醒；已关闭会话或残留旧任务上下文仍拒绝，避免旧任务文案误用。
- 已修改 `AppSessionCoordinator.refreshTaskContext()`：任务结束并切换到无任务上下文后，只要目标应用仍在前台，仍可安排提醒；保留原应用使用会话，不另算一次打开。
- 已修改 `ReminderScheduler`：触发前以及延迟后检查当前守护开关、受守护应用名单；读取文案后再次复查。原有延迟、普通额度、前台检查、会话检查和去重保留。
- 公共校验修正也适用于调用该方法的稍后提醒、提醒 Activity 与按钮处理；未在本轮执行第 3 项的完整链路重构或验收。
- 补充 7 个回归测试用例源码：无任务、未来／已完成任务、正常延迟、延迟期间关闭守护、延迟期间移出名单、开始时关闭守护、任务结束后持续安排提醒且不拆会话。
- 检查：指定文件 `git diff --check` 通过；6 个 Kotlin 文件的导入格式、括号配对静态检查通过。上述检查不等于 Kotlin 编译或行为测试通过。

## 2026-08-06

### 问题 1：提醒弹窗不出现（真机实测）

**现象**：安装后页面显示正常，但打开目标 App 后没有任何提醒弹窗；首次打开 App 时也没有权限提示。

**根因分析**（按调用链逐层排查）：

1. 引导页选择检测方式后，只跳转系统设置页并标记引导完成，**没有把所选模式写入应用设置**。
   `enableAccessibility` 默认值为 `false`，且唯一的写入点是设置页的「启用无障碍检测」开关。
2. `FocusAccessibilityService.shouldProcessAccessibilityEvents()` 要求
   `detectionMode == REALTIME && enableAccessibility` 同时成立；开关为 false 时，
   无障碍事件在入口被直接丢弃 → 不产生会话 → 不触发提醒。
3. 兼容模式同理：`MainActivity` 仅在 `detectionMode == COMPATIBILITY` 时启动检测服务，
   引导页同样没有写入该值，服务不会启动。
4. 「首次打开无权限提示」符合当前设计（应用不主动请求权限，仅由引导按钮跳系统页）；
   一旦完成过引导（SharedPreferences 标记），之后直接进入首页。

**修复**：

- 引导页选择检测方式时即调用 `SettingsViewModel.applyOnboardingDetectionMode(mode)`，
  持久化 `detectionMode` 与 `enableAccessibility`。
- 设置页监听生命周期：实时模式下若系统无障碍已开启，自动把应用内开关置为开启
  （`ensureAccessibilityEnabled()`），即使之前没手动开开关也能恢复检测。
- 「启用无障碍检测」开关与实时模式选中时，未开启则跳转系统无障碍设置页。
- 引导页进入 AI 配置步骤时（Android 13+）请求通知权限，实时模式同样覆盖。

### 问题 2：弹窗可能被静默吞掉（悬浮窗与通知权限）

**现象**：即使检测链路通了，也可能看不到任何提醒。

**根因分析**：

1. 提醒展示依赖「显示在其他应用上层」（SYSTEM_ALERT_WINDOW），
   无权限时降级为通知；但应用内**没有任何地方引导用户开启悬浮窗权限**。
2. Android 13+ 通知需要运行时权限，实时模式路径此前不会请求通知权限；
   通知被拒绝时降级通知也会被系统丢弃。

**修复**：

- `PermissionHelper` 增加悬浮窗权限检测与跳转（`ACTION_MANAGE_OVERLAY_PERMISSION`）。
- 设置页「检测方式」分组新增悬浮窗权限状态行与「去开启」入口，并在返回页面时刷新状态。
- 切换到任一检测方式时都会请求通知权限（Android 13+）。

**验证方式**：Android Studio 构建后真机复测——目标 App 打开后停留超过提醒延迟，
应出现悬浮窗弹窗或通知；首次引导完成后检查设置中的检测方式与无障碍开关状态。
