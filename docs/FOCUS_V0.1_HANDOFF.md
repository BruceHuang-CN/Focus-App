## 已确认的产品规则

- 目标应用以短视频和信息流应用为主，包括抖音、哔哩哔哩和小红书，并允许用户配置。
- 用户可创建任务，也可为任务设置时间段；当前任务和用户状态共同构成 AI 提醒上下文。
- DeepSeek 等 API 是核心能力，不能移除。当前实现默认使用 DeepSeek V4 Flash，并关闭 thinking 模式。
- 每次任务激活或时间段切换时，AI 一次生成 3 条短提醒并缓存在本地轮换。这不代表只允许提醒 3 次；窗口内次数和每日次数由独立规则控制。
- 切换任务或时间段会更新提醒内容，但不会重置当前统计窗口的已提醒次数。
- 提醒延迟预设为 3/10/30 秒并支持自定义；统计窗口预设为 30/60/120 分钟并支持自定义；窗口内次数预设为 1/3/5 次并支持自定义；每日上限也允许自定义。
- 提醒口吻允许用户选择强度或风格。
- 点击“不刷了”等主动退出操作后，优先返回 Focus，也可选择返回桌面。
- 低内存、低耗电优先：实时模式不使用固定轮询；API 内容提前生成并缓存；统计查询限定时间范围。
- 首页采用已确认的 A 方案：当前任务优先显示。
