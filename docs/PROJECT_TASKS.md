## 当前最高优先级：提醒可靠性

- [x] **P0：稳定稍后提醒所绑定的目标 App 会话。** 用户选择 1/5/10 分钟或自定义分钟后，临时 Focus 弹窗、键盘、权限窗口和通知栏不能误关会话或取消提醒。
- [x] **P0：真实离开前执行一次延迟复核。** 检测到非目标窗口后等待 1.5 秒并复核真实前台；目标 App 已恢复则继续计时，仍为其他 App 才确认离开。
- [x] **P0：真正离开目标 App 后取消本次稍后提醒。** 不发送到期通知，也不弹出提醒；关闭守护或目标应用移出守护范围时同样取消。
- [x] **P0：稍后提醒到期后不再静默丢失。** 前台状态无法确认（缺少使用情况访问权限或系统事件）时不再视为已离开；锁屏改为重试而非放弃；新增进程内准时调度 + WorkManager 兜底，避免 1/5/10 分钟与自定义分钟到期后毫无提醒。待真机回归确认。
- [ ] **P0：补齐稍后提醒回归场景。** 覆盖自定义 3 分钟、临时弹窗、真正离开、快速离开后返回、进程重启和关闭守护。
- [ ] **P0：修复额度统计模型。** 当前一个会话只保存一个 `remindedAt`，重复提醒可能覆盖或误计数；改为独立提醒事件记录，并让“重置额度”只重置当前统计周期，不篡改历史使用数据。
- [ ] **P0：减少无障碍事件造成的碎片会话。** 对键盘、系统弹窗、透明 Activity 和快速窗口切换增加短暂防抖与前台包名复核，避免首次延迟尚未到期就错误结束会话。

## 已知边界

- Android 系统或 Android Studio 对应用执行“强制停止”后，应用进程、无障碍以外的服务和 WorkManager 都不能自行运行；后台锁定和电池白名单不能绕过该系统限制。
- 已在 realme RMX3350（Android 11 / ColorOS V11.1）观察到 OEM 冻结：无障碍系统开关可保持开启，但服务可能未绑定、应用进程可能处于 `freezer:/frozen`；当前不能把实时模式标记为已在后台完全可靠。
- 不通过持续高频轮询换取表面保活；优先采用系统事件、一次性 WorkManager、通知和状态恢复机制。
- 在未获得二维码、链接或收款信息前，不填入任何真实外部联系方式或收款信息。
