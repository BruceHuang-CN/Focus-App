### 3.2 视觉与点击规则

- 页面外边距 16–20dp，组卡间距 12–16dp；组卡圆角约 26dp，内部任务行约 18dp。
- 大标题约 32–36sp，组标题约 20sp，任务名约 16sp。避免直接把参考图像素换成 dp。
- 组头左侧圆形浅绿图标底座，右侧当前组标签与展开箭头；只点击组头折叠，不让设置按钮误触折叠。
- 当前组默认展开；其他组默认收起。允许多组展开，按组 ID 保存状态，返回页面后恢复。
- 折叠状态保留组名、任务数量、星期与时段、两个组操作，隐藏组内任务和添加入口。
- 任务标题最多显示两行；超长内容在编辑页完整查看，避免把右侧菜单挤掉。
- 圆圈使用有选中语义的完成控件，点击记录完成；完成项默认移入组内“已完成”折叠区，可恢复。
- 更多菜单：设为当前任务、编辑、移动到组、删除；删除显示确认，防止误操作。
- 新建任务组打开编辑底部面板：名称、预设图标、时段／重复星期。编辑任务沿用已有标题和时间校验能力。
- 新建组为空时显示“还没有任务”和“添加任务”，不生成假任务数。
- “设为当前组”与“设为当前任务”明确区分：组内始终选出一个具体的未完成任务供首页和提醒使用。
- 若从底部导航直接进入一级任务页，不设置没有明确目标的返回箭头；从二级导航进入才显示返回入口。

### 3.3 真正的任务组数据

这是实现参考图的必要工作，不能延后到“以后有空再做”，也不能靠将所有任务临时放进一个写死的组冒充完成。

最小实现：

1. 新增任务组 Entity／DAO／Repository，保存名称、图标、顺序和组时段。
2. 给任务增加 groupId 和稳定排序；保留旧 taskId、完成状态和历史引用。
3. 迁移旧任务：相同有效计划可归入同组，无时段任务放入“未分组”；旧配置异常时提示修正，不静默覆盖时间。
4. 删除组默认让用户选择迁移任务或明确删除，历史统计不随组删除。
5. 新任务默认继承组时段，旧任务的不同时间配置保留为可见例外，避免升级改变用户安排。

推荐的调度规则：有计划的组只在其有效时段内提醒；时段外手动启动时明确选择临时期限；完成当前任务后选择组内下一项未完成任务。此处是计划中的推荐行为，执行时需明确采用的规则并记录，不能继续保留“手动当前永久覆盖时段”的隐式行为。

旧计划已发现手动激活和稍后提醒缺少时段约束。设置时段、设为当前与提醒资格必须作为一条链实现和审阅，不只保证界面上的时间能保存。

### 4.2 概览指标

建议五项为：打开次数、回到任务次数、有目的使用次数、提醒覆盖率、目标应用使用时长。

- 容器、图标、字号与留白按参考图做，数据名称按实际能力确定。
- “专注时长”不能使用现有目标应用时长代替，也不能用计划时长冒充；真正专注计时另立功能。
- 提醒覆盖率定义为所选期间开始的会话中至少实际展示过一次提醒的会话数／该期间打开会话数；分母为 0 显示“—”。
- 顶部范围控制概览与行为分布；卡片标题同步变为今日数据、最近 7 天数据或最近 30 天数据。
- 320–400dp 宽度使用 3＋2 或两列排列；仅有足够空间才五项并排，避免标签和分钟单位拥挤。

### 4.3 提醒活动热力图

- 延续用户此前提出的周、月、年方向，标签明确为“本周／本月／本年”，独立于概览日期筛选。
- 本周显示 7 个日期格；本月按星期对齐日历；本年按周列排列，一格一天，月份标签与格子对应。
- 年视图默认定位到当前月份；横向可滚动，不能把全年强行压成难以点击的小点。若宽度足够可显示更多周。
- 本周／本月／本年统一使用绿色格子和少到多图例，避免切换后完全变成另一类图。
- 点击日期显示日期、真实提醒展示次数，并提供当天明细；年份切换处理闰年及跨年周。
- 0 次、尚未来到的日期、历史缺失使用不同说明；有数据才涂色。
- 提醒越多仅代表干预越频繁，不把深色解释为专注成绩越好。
- 由实际展示事件聚合，不能用打开次数代替提醒次数；额度重置不得删除这些历史。

### 4.4 行为分布环图

- 保留参考图中“左侧环图、右侧三行明细”的结构；窄屏或大字体下上下排列。
- 环图中心为已记录选择总次数；旁边显示颜色标识、名称、次数和百分比。
- 使用真实动作“回到任务／有目的使用／休息一下”；不能照搬旧截图名称却关联错误数据。
- 需要独立动作事件，以 attemptId 去重。一个会话多次提醒的选择分别记录，而不是只看会话最后一次动作。
- 返回桌面、返回回神、返回指定应用归入“回到任务”的返回动作组；旧的 snoozed／continued 做明确映射或单独标为旧记录。
- 无响应不自动算成有目的使用；历史只有末次动作的记录不能伪造成完整事件。
- 空数据用中性空环与“暂无已记录选择”，不保留示例 12 次或示例百分比。

### 4.5 原有图表与末尾入口

- 按小时使用、每日时长趋势、各应用占比保留在“使用详情”二级页面，主页面不再铺开这些旧模块。
- 统计页末尾仍保留“今日状态”，按参考图的末尾卡片设计图标和层次。
- 暂不启用 AI 回顾或“生成今日小结”；未接入时不显示可点击箭头或按钮，不调用 API。
- 参考图右上的叶片可作为统计页静态装饰，窄屏优先隐藏；不恢复首页此前明确删除的草叶，不强制加入竖排标语。
