# 设置页结构重做交付说明

项目：`D:\Project\Focus-App-UI-improve`，分支：`codex/ui-optimization`。

## 本轮改动

- 首页改为大标题与保存状态胶囊、七组大圆角卡片、统一浅色设置行。沿用现有主题色与日夜模式。
- 分组为：提醒与守护、权限与系统状态、外观主题、提醒偏好、应用与返回、AI 提醒、反馈与支持。
- 保留强制提醒、提醒延迟、呼吸停顿、随机按钮、窗口时长和次数、应用组、自定义返回应用、实时无障碍检测及常驻守护。
- 数值点击后打开底部选择面板，预设与自定义输入共存；超范围／空输入不能确认，不在输入过程中强制改写数字。
- AI 配置改成按需进入的页面，保留服务商、端点、模型、密钥、连接测试、口吻与预览。密钥遮罩显示、不保存到界面恢复状态；保存成功才清空输入。修改连接配置后旧测试结果失效。
- 额度重置与文案重新生成共用管理面板，复用已有用例；无有效任务时提示仍可使用通用守护提醒。
- 权限概要在普通手机宽度下三列展示，窄屏或大字体改为纵向；完整面板保留使用情况访问、通知、系统无障碍、应用内检测开关及后台设置。
- 删除首页原有“保存设置”按钮的假保存交互。设置写入串行处理，显示保存中／已保存／失败状态；AI 输入草稿单独提示，离开提示不再声称点击离开就会保存。

## 流畅度处理

- 首页使用单个 LazyColumn，以固定 key／contentType 组织分组；回到首页保留滚动位置。
- 各分组按生命周期订阅相关状态；配置表单和底部面板仅在打开时组合。
- 权限检查与应用名称读取放到 IO 调度器；界面不在滚动中轮询权限。
- 使用原生圆角、矢量图标和现有主题色，不增加大面积模糊、重阴影、全页缩放动画或新的 UI 依赖。

## 检查与验收边界

源码导入格式、括号及缓存图标声明静态检查无问题；差异格式检查通过。新增保存失败可重试、连续开关写入顺序两项测试源码；新增日间、夜间和大字体的组件 Preview 源码。

没有编译、运行测试、渲染 Preview 或进行帧率测量，没有安装 APK，没有提交或上传 GitHub。不能把源码检查视为编译通过或不卡顿的证明。

## 建议在 Android Studio 验证

1. 设置首页是否为紧凑分组卡片，强制提醒与延迟入口是否明显；底部内容不被导航栏遮挡。
2. 日间／夜间／跟随系统及原有四种主题色正常切换，文字、开关和图标对比清晰。
3. 快速滑动、切换主题、打开／关闭底部面板、弹出键盘时的实际流畅度；应在接近正式发布配置的构建中评估性能。
4. 从设置中部进入 AI 配置再返回，滚动位置保留；大字体和窄屏下权限卡片与选项不挤压。
5. 提醒延迟支持 1–300 秒，提醒窗口支持 5–1440 分钟，次数支持 1–20 次；清空或越界输入不可确认，取消面板不写入。
6. 开关写入完成才显示已保存；保存失败能重试。可运行 `SettingsViewModelDetectionTest` 与 `SettingsViewModelAiConnectionTest`。
7. API 输入在本页返回／切换底部标签时有未保存提示；密钥保存失败仍保留输入，成功后清空，连接测试不能将过时结果标成成功。
8. 权限从系统设置返回后刷新；守护、强制提醒、呼吸、常驻通知、应用组和返回应用保持原功能。
9. 额度重置不删除统计历史；生成文案显示忙碌状态并防止重复点击，失败保留原文案。
