## 3. 日间与夜间视觉规范

### 3.1 视觉方向

关键词：深森林绿、偏冷浅绿背景、清晰深色标题、圆润卡片、低对比内层容器、克制的线性图标。

“颜色更深”主要体现在主按钮、标题和选中态。日间背景仍保持明亮；夜间使用深绿灰层次，不把所有区域涂成同一种黑绿，也不沿用纯白提醒卡片。

### 3.2 候选语义色值

以下是根据参考图拟定的设计值，不声称为图片精确取色。实现时检查实际前景／背景组合的对比度，再微调。

|---|---|---|
| 页面背景 background | `#EDF6ED` | `#101A14` |
| 主卡片 surface | `#FFFFFF` | `#1A2820` |
| 内层容器 surfaceContainer | `#F2F6F2` | `#23352A` |
| 主色 primary | `#205C35` | `#9CD4AA` |
| 主按钮文字 onPrimary | `#FFFFFF` | `#102A19` |
| 选中背景 primaryContainer | `#DDEEDD` | `#294C35` |
| 选中文字 onPrimaryContainer | `#143E22` | `#D7F0DC` |
| 主要文字 onSurface | `#102416` | `#E6EEE7` |
| 次要文字 onSurfaceVariant | `#5E6D63` | `#B1C0B5` |
| 分隔与描边 outlineVariant | `#CDDCCF` | `#42574A` |

夜间主按钮使用柔和浅绿配深色字，区别于深背景；不要为了“更深”牺牲按钮可辨认度。提醒页应用名称和任务名称以主色＋字重强调；红色主要用于错误或确有必要的紧迫提示，不把所有重要文字都染红。

普通文字目标对比度至少 4.5:1；大字及关键图形至少 3:1，状态同时使用图标和文字表达。图表热力级别明确标注从少到多，不仅靠颜色传达含义。

### 3.3 尺寸、字体、图标

- 使用系统中文字体，页面标题约 30–34sp／粗体；区块标题 18–20sp；正文 15–16sp；辅助信息 12–14sp。实际响应系统字体缩放。
- 不照搬长图的大标题像素高度；Android 小屏首屏应能看到主要内容。
- 页面边距 16–20dp，区块间距 12–16dp，主卡片圆角 24–28dp，内部容器 16–20dp。
- 主操作最小高度 48–52dp；图标视觉大小约 20–24dp，点击区域至少 48dp。
- 线性图标为主，选中态可用实心版本；不使用跨设备渲染差异很大的 emoji 作为主要图标体系。心情表情改为本地矢量或简单 Canvas 表情，保留文字标签。
- 底部导航采用参考图的独立圆角容器；选中项深绿／夜间浅绿，未选中用次要文字色。给滚动内容留足底部空间，避免悬浮导航遮住末项。
- 日间可以使用极轻的背景渐变；夜间以表面层次区分卡片，避免大面积亮光晕。

### 3.4 主题接入

- 在 `ui/theme/Theme.kt`、`Color.kt`、`Type.kt` 定义统一语义样式；必要时增加轻量的 Shapes／Spacing，不为本次改版建立庞大设计系统。

## 5. 呼吸动画：从屏幕边缘持续汇聚，结束即消失

### 5.1 当前实现与差异

源码 `BreathingScreen.kt` 中动画画布固定为 320dp，粒子起点由该局部画布半径决定，不能真正从屏幕边缘进入。

现有 5 秒时序大约是：1.2–2.8 秒完成聚合，2.6–3.4 秒成球，3.4–4.6 秒保持脉动，4.6 秒后提前淡出。倒计时由 `ReminderOverlay` 逐秒 delay 驱动，球动画又有自己的 Animatable，因此不是同一个连续时间源。

新需求需要同时调整绘制区域与时间轴，不能只改颜色或放大起点系数。

### 5.2 新几何规则

- 改为页面背景层的全可用尺寸 Canvas，不把整个画布或中央球等比放大。
- 起点分布在可见安全区域四条边附近，留约 4–8dp；同时计入粒子自身半径，避免刚出现就被裁掉。这里将“几个像素”落实为适应不同屏幕密度的少量边距。
- 边缘指应用可绘制区域边缘，不强行覆盖刘海、系统栏或手势区域。
- 中心目标锚定中央球的实际位置；为标题、倒计时和按钮预留区域，粒子放在文字后方并降低交叉区域亮度。
- 起点每次提醒生成一次，使用 attemptId 的稳定种子；重组和旋转不重新随机。
- 保持当前中央球的最终视觉尺寸作为基准，不因画布改为全屏而变大。现有实体球名义半径约 32dp，可在预览中小幅校准；光晕不算实体球尺寸。
- 中央球随汇聚逐渐形成，不出现提前完成后半径固定停留一秒的阶段。终点不采用放大爆开效果。

### 5.3 新 5 秒时间轴

| 时间 | 粒子与中央球 | 倒计时 |
|---|---|---|
| 0–0.25s | 边缘粒子短暂渐显，并立即开始移动 | 5 |
| 0.25–4.75s | 持续向中心移动，起点和轨迹轻微错开；中央球渐进形成，保留到末段仍在汇入的粒子 | 5、4、3、2、1 |
| 4.75–5.00s | 最后粒子汇入，保持运动连续；中央球仍可见，不提前进入静止保持或消失阶段 | 1 |
| t ≥ 5.00s | 中央球与剩余粒子直接不再绘制，切入提醒决策页 | 不额外停留在 0 |

球消失以后可以让决策内容做 120–180ms 的轻淡入；淡入过程中不保留旧球，不添加额外等待。避免 Crossfade 将旧呼吸图层保留到倒计时之后。

“大小不变”按本次上下文理解为拒绝旧版“提前形成固定大小的大球并停留”的效果；最终球的设计尺寸保持，不增加停留阶段。前半程允许球随汇聚逐步形成。

### 5.4 一个时间源

- 用一次呼吸开始／结束时刻作为单一依据，单调时钟计算 elapsed、progress 与剩余秒数；数字按剩余时间向上取整。
- 每帧位置由同一 progress 计算，不继续维护逐秒 delay 链与独立动画之间的双时钟。
- 同 attemptId 的旋转／重组不重播；运行中改变主题只换颜色，不重置时间。
- 前后台切换按原截止时间计算，返回时若已结束则直接进入决策页；进程恢复保存足够的时间信息并识别失效时钟基准，不能出现负数倒计时或无限停留。
- 关闭系统动画时使用弱运动或静态倒计时，5 秒业务等待与结束条件保持一致。
- 粒子数量先沿用当前 10 个；轨迹和随机参数预先计算，动画值在绘制阶段读取，不让整页跟着每帧重组。无需持续后台动画、模糊库或物理模拟引擎。
